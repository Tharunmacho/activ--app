# ACTIV

Full-stack monorepo for the ACTIV membership platform: a React Native mobile
app and the Express/MongoDB API it talks to.

```
activ--app/
├── docs/         System specifications, workflow and API documentation
├── frontend/     React Native app (TypeScript)
├── backend/      Express.js + MongoDB API (/api/v1)
└── CLAUDE.md     Engineering directive — read before changing code
```

---

## Quick start

### Backend

```bash
cd backend
npm install
cp .env.example .env        # then fill in MONGO_URI, JWT secrets, etc.
npm run dev                 # nodemon on the port from .env (default 5000)
```

### Frontend

```bash
cd frontend
npm install
npx react-native start      # Metro bundler
npx react-native run-android   # or run-ios
```

The API host the app talks to is set in `frontend/src/config/api.config.ts`.
For a physical Android device either set `DEV_HOST` to your machine's LAN IP,
or keep `localhost` and forward the port:

```bash
adb reverse tcp:5000 tcp:5000
adb reverse tcp:8081 tcp:8081
```

Uploaded images are stored as relative `/uploads/...` paths and resolved
against that same host at render time, so they follow whatever API origin the
app is using.

## Tests

```bash
cd backend
npm run test:workflow                              # unit tests, no DB needed
PORT=5055 node src/server.js                       # spare port; 5000 is often taken
BASE_URL=http://localhost:5055 npm run test:e2e    # against a live DB
```

Type safety for the app — this must report zero errors:

```bash
cd frontend
npx tsc --noEmit
```

## Database scripts

One-off seeders and sanity checks live in `backend/scripts/`. Run them from the
`backend` directory:

```bash
cd backend
node scripts/seed-all-admins.js
node scripts/check-db.js
```

They load `backend/.env` by absolute path, so they work from any working
directory.

## Native build artifacts

`android/app/build/`, `android/app/.cxx/`, `android/prefab-cache/` and
`android/.gradle/` are generated by Gradle and can reach well over a gigabyte.
They are ignored by git and must never be committed — they are what makes a
push time out. Delete them freely; the next build regenerates them:

```bash
cd frontend/android
rm -rf app/build app/.cxx prefab-cache .gradle build
```

If a push is ever slow despite a clean tree, repack the object store:

```bash
git gc --prune=now
```
